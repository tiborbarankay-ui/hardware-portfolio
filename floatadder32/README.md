## 32-bit floating point number adder

This is a simple 32-bit floating point adder, written in Verilog, I designed for a class assignment. Verified with the corresponding testbench I designed.

## Files
- 'floatadder32.v' - The design
- 'floatadder32_tb.v' - testbench

## Simulation
Run with ModelSim: vlog floatadder32.v floatadder32_tb.v; vsim floatadder32_tb; run -all
